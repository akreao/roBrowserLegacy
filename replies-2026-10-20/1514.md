## GUIComponent.js: a deferred default image overwrites a state image

Fixed in 5eb338fd. A `data-background` fetched late no longer replaces a background the window has set on that node in the meantime. Examples are BasicInfoV0's mini layout and Storage's selected tab. Hover, down and active states still restore the default on mouse-out, as before. `GUIComponentLazyImages.test.js` adds a test that sets a state background before the window is drawn and checks that it is kept.

## WhenDrawn.js: closed windows stay in the shared observer

Fixed in 5eb338fd. `whenDrawn` gains `suspend(host)` and `resume(host)`. These cover the host and everything under it in its light and shadow DOM. `GUIComponent` suspends after `prepare()` and in `remove()`, and resumes in `append()`. So a window that is closed, or prepared and never shown, is no longer watched, and its pending callbacks go with its nodes. A reused window is watched again when it is appended. Tests are in `WhenDrawn.test.js` and `GUIComponentLazyImages.test.js`.
