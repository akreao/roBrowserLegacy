## WhenDrawn.js: closed windows keep pending observers alive

Fixed in #1514's commit 5eb338fd, which this branch carries. `GUIComponent` stops watching a window's pending art when it is taken off the page (after `prepare()` and in `remove()`) and watches it again on `append()`. This covers the host element itself, which this PR's windows register, and nodes created in `prepare()` that are never appended. Tests are in `WhenDrawn.test.js` and `GUIComponentLazyImages.test.js`.

## PvPCount.js: a 0/0 ranking stays blank

This one stays as it is. `ranking` and `total` start at 0, so `setData` with 0/0 returns at its "unchanged" check before drawing anything, on `master` as well. This PR doesn't change that. Making 0/0 draw would be a behaviour change of its own, so I've left it out of a performance PR.

## Former party members remain highlighted

Fixed in 0d9d4ca (#1514's branch, which this branch now carries). `onPartyMemberLeave` calls the new `WorldMap.removePartyMember(AID)`: a member who leaves is dropped from `_partyMembersByMap`, and when it is us the whole list is cleared. The built sections are re-marked at once, and sections built later read the current list. On master the already-built sections kept the old mark too; this covers both. A test in `tests/ui/WorldMapParty.test.js` checks a member leaving, a rebuild, and our own leave.

## Deferred backgrounds preserve any inline image

Fixed in 0d9d4ca. The node's inline background is now recorded when its art is deferred, and the late default is skipped only when the window has changed it since (the mini layout, a selected tab). An inline image the node already had keeps being replaced by its `data-background`, as on master. Stateful buttons are unaffected either way: the default art's URL is still stored, so hover, mouse-out and the `active` class switch back to it as before. A test covers a template inline image.
