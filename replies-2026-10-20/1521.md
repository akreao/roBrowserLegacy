## 🔴 Slow-frame measures grow without limit
Fixed in 43a99b0. Once the slow-frame log reaches 1,000 entries, the probe stops adding `roPerf slow frame` measures too, and `reset()` clears them with `performance.clearMeasures`. A test checks that 1,200 slow frames give 1,000 measures.

## 🟡 Renderer pauses become false hitches
Fixed in 43a99b0. `Renderer.stop()` now calls `PerfProbe.stop()`, which clears the previous frame's timestamp. The first frame after the loop starts again only sets the clock, and the measurement window carries on. A test covers a 30 s pause.

## 🟡 Waterfall vertex totals omit instances
Fixed in 43a99b0. `drawArraysInstanced` and `drawElementsInstanced` now add count × instance count, so the 640-particle waterfall counts 2,560 vertices. A test covers both calls.

## 🟡 Map loads lower reported frame rate
Fixed in 43a99b0. `fps` now comes from the kept frames' intervals, so map loads and pauses no longer lower it. `stats().drawingSeconds` gives that drawing time, and `/perf` reports "fps over N s of drawing". `seconds` is still the wall-clock window. A test covers 6 s of drawing plus 5 s of loading.

## 🔍 Reset mixes new frames with old marks
`reset()` now clears the map marks, so a window holds only the maps loaded inside it (43a99b0). The login mark stays, because it is the startup time and happens only once per session.

## 🔍 Slow-frame listing hides its cap
Fixed in 43a99b0. `stats().slowFrames` counts every slow frame since the reset. When that is more than the list holds, `/perf slow` says "N frames over 33 ms since the last reset; the first 1000 are listed." The list keeps the earliest frames, which are the ones that also have measures.
